# Install Deepal Companion

Follow the [step-by-step installation guide](docs/INSTALLATION.md).

- Repository: `https://github.com/rmxs/deepal-S05-Companion`
- Home Assistant 2026.11+: **Settings → Marketplace → Add from link**. Add the repository, open it and select **Install**.
- Earlier supported versions: add the repository in **HACS → Custom repositories** as an **Integration**, download and restart.
- Setup: **Settings → Devices & services → Add integration → Deepal Companion**.
- Next: follow the [user guide](docs/USAGE.md).
