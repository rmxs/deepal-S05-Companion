Before you start — three rules that make the rest correct

  • Only source/card.js is edited by hand. custom_components/deepal_companion/defaults.json and setting_keys.json are generated: scripts/build.cjs writes both from DEFAULTS in source/card.js. Editing those JSON files directly is undone by the next build.
  • Finish with npm run build. It also regenerates the .js.gz files; if you edit a bundle by hand its .gz stops matching and Home Assistant serves the old one.
  • Add one CHANGELOG.md line under 2.0.1 (text at the bottom of this page). No scripts/update-project-map.cjs run is needed: no file is added, removed or moved.
